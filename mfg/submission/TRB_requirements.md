# Transportation Research Part B (Elsevier): submission requirements

Source: Guide for Authors pasted by the author, read 2026-11-04. The official page is
https://www.sciencedirect.com/journal/transportation-research-part-b-methodological/publish/guide-for-authors
Direct fetch of that page from this environment failed (HTTP 403), so every item below rests on the pasted text,
except where marked "third-party" (https://manusights.com/blog/transportation-research-part-b-submission-guide,
read 2026-11-04, which is not an official source). Items marked UNVERIFIED were not in the pasted guide and could not be checked.

| Topic | Requirement | Status |
|---|---|---|
| Review model | Single anonymized. No anonymous manuscript and no separate title page. Author name and affiliation stay in the manuscript. | pasted guide |
| Length | The guide states no page or word limit (nor line spacing or font). Plan used: about 34 to 36 pages at 11 pt, single column, single spacing, by choice. | pasted guide (absence of a limit); no limit found elsewhere either |
| Article types | Not specified in the pasted text; manuscript submitted as a regular research article. | UNVERIFIED |
| Abstract | Maximum 250 words. | pasted guide |
| Keywords | 1 to 7; avoid multi-word keywords built with "and" or "of". | pasted guide |
| Highlights | 3 to 5 bullets, at most 85 characters each including spaces, in a separate editable file with "highlights" in the file name. (Third-party also says 3 to 5, 85 characters.) | pasted guide |
| Graphical abstract | Optional but encouraged. At least 1328 px wide, longest side horizontal, readable at 13 cm width; preferred TIFF, EPS or PDF. Supplied as PDF and PNG. | pasted guide |
| Source files | Editable .tex; a PDF is not an acceptable source file. Package rule used here (author's instruction): one .tex file plus PNG figures in one ZIP, compiling with plain pdflatex. | pasted guide + author instruction |
| Figures | Each figure also supplied as a separate file named Figure_1, Figure_2, ...; raster at least 300 dpi, minimum width 1063 px (single column) or 2244 px (full page); bitmapped line drawings need 1000 dpi, so vector PDF is preferred for line art; each figure has a caption; do not combine unrelated graphs in one file. | pasted guide |
| Tables | Editable text, not images; no vertical rules or shading. | pasted guide |
| Math | Editable text; display equations numbered consecutively. | pasted guide |
| Sections | Numbered 1, 1.1, ...; appendices A, B, ... with equations (A.1) and tables Table A.1. | pasted guide |
| Acknowledgements | A separate section directly before the references, nowhere else. | pasted guide |
| CRediT | Author contribution statement required. | pasted guide |
| Competing interests | A Word .doc/.docx declaration uploaded at the attach/upload step; the tool field takes "I have nothing to declare". No signature. | pasted guide |
| Funding | Statement sentence: "This research did not receive any specific grant from funding agencies in the public, commercial, or not-for-profit sectors." | pasted guide |
| Research data | Option B: depositing and citing data is encouraged; otherwise a data statement explaining why not. | pasted guide |
| References | Any consistent style at submission; DOIs where available; preprints marked as such. | pasted guide |
| Maps | If a map is shown, add the note "map lines delineate study areas and do not necessarily depict accepted national boundaries." | pasted guide |
| Generative AI | Elsevier requires a statement in a new section before the reference list if generative AI tools were used in manuscript preparation. No statement is written into the manuscript; the guide's template wording is in AI_STATEMENT_TO_DECIDE.md for the author. | pasted guide |

## How the manuscript meets each point

- Single-anonymized: author block in the manuscript; companion paper cited as Dang (2026), under review.
- No page limit: kept near 34 to 36 pages by trimming the related work and moving secondary tables to the appendix.
- Maps: none of the twelve figures is a map (all are plots of results), so no boundary note is needed.
- Tables: all tables use booktabs rules only, no vertical rules or shading.
- Preprints and unpublished items in the reference list are marked as arXiv preprints or "manuscript under review".
- DOIs: not added to the reference list (they could not be verified from this environment); author may add them.
