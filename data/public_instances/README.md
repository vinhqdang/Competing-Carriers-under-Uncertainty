# Public VRP instances

Small text files, unchanged except that Windows line endings were removed from the Solomon files.
All were downloaded on 2026-10-26 from the web page of the NEO group (University of Malaga), which mirrors the original benchmark sets:

| Directory | Instances | Original source | Downloaded from |
|---|---|---|---|
| `solomon_100/` | R101-R112, C101-C109, RC101-RC108 (100 customers) | M. M. Solomon, "Algorithms for the vehicle routing and scheduling problems with time window constraints", Operations Research 35(2), 1987 | https://neo.lcc.uma.es/vrp/wp-content/data/instances/solomon/solomon_100.zip |
| `solomon_50/` | same, first 50 customers | same (truncated sets of the Solomon website) | https://neo.lcc.uma.es/vrp/wp-content/data/instances/solomon/solomon_50.zip |
| `solomon_25/` | same, first 25 customers | same | https://neo.lcc.uma.es/vrp/wp-content/data/instances/solomon/solomon_25.zip |
| `augerat_A/` | A-n32-k5 ... A-n80-k10 (CVRP, TSPLIB format) | P. Augerat et al., "Computational results with a branch and cut code for the capacitated vehicle routing problem", 1995 | https://neo.lcc.uma.es/vrp/wp-content/data/instances/Augerat/A-VRP.zip |
| `augerat_B/` | B-n31-k5 ... B-n78-k10 | same | https://neo.lcc.uma.es/vrp/wp-content/data/instances/Augerat/B-VRP.zip |

Index pages: https://neo.lcc.uma.es/vrp/vrp-instances/capacitated-vrp-with-time-windows-instances/ and https://neo.lcc.uma.es/vrp/vrp-instances/capacitated-vrp-instances/.

Licence: the benchmark sets carry no licence text in the files or on the pages above. They are distributed there for academic research. They are redistributed here unchanged in content, for reproducing `experiments/run_brl_bench.py`; please cite the original authors. If a rights holder objects, delete the directory and download the files from the URLs above.

Not obtained: the instances of Zhang, Zhang, Lim and Sim, "Robust data-driven vehicle routing with time windows" (Operations Research 2021). The INFORMS supplement page (https://pubsonline.informs.org/doi/suppl/10.1287/opre.2020.2043) is behind a bot check and returned HTTP 403, and no public mirror was found. The Adulyasak-Jaillet instances were not found either. Both criteria are therefore *emulated* on Solomon and Augerat data, see `docs/EXPERIMENTS.md`.

The uncertain travel times are not part of these files. They are generated by `experiments/run_brl_bench.py` from a documented seed.
